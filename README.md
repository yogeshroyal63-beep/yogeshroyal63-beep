## Featured Projects

**GhostID** is a behavioral biometrics SDK for continuous keystroke-based session verification, built around a 2-layer LSTM trained on the CMU Keystroke Dynamics dataset and exported to ONNX for fast inference. The core idea is ratio-preserved features that survive typing speed variation, so an impostor can't fake identity by simply typing faster or slower. It ships with a FastAPI backend, a vanilla JS SDK, and a React dashboard.

**MedAssist** is a full-stack healthcare platform combining a React/Vite frontend, a Node.js/Express backend, and a Python FastAPI service running a BERT-based triage engine. It supports WebRTC video consultations and real-time chat via Socket.io, with the whole stack orchestrated through Docker Compose.

**Wraith** is a sales AI built for the FlowZint AI Hackathon 2026, pairing a real-time whisper copilot for live sales agents with a rejection intelligence engine that mines failed calls for objection patterns. It uses a fine-tuned DeBERTa-v3 stage classifier, BERTopic clustering for rejection analysis, and a self-improving feedback loop, with a React + FastAPI + MongoDB stack deployed on Vercel and Railway.

**Smart Allowance** is an AI-powered blockchain allowance system deployed on Base Sepolia, built for The Synthesis Hackathon 2026 across three separate tracks. It uses an LLM-driven agent to manage allowance logic and payments autonomously, with a live frontend and Railway-hosted backend.

**VaultMind** is an authorization runtime for multi-agent AI systems, built on Auth0 Token Vault with intent-bound single-use tokens and natural language policy compilation into OAuth scopes. It handles trust decay and cryptographic delegation chains for AI agents that need scoped, auditable permissions.

**Sentinel** is an intent enforcement system for autonomous financial agents, built using the OpenClaw framework with Ed25519 cryptographic signing, execution tokens, and an immutable audit ledger, backed by a real subprocess kernel communicating over a Unix domain socket.
