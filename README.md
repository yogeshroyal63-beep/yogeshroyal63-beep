## Featured Projects

**GhostID** — AI-powered continuous authentication that prevents session hijacking using behavioral biometrics with zero user friction. A 2-layer LSTM trained on the CMU Keystroke Dynamics dataset uses ratio-preserved typing features that survive speed variation, so an impostor can't spoof identity by typing faster or slower. Ships as a FastAPI backend, JS SDK, and React dashboard, with the model exported to ONNX.

**MedAssist** — Full-stack healthcare platform with React/Vite frontend, Node.js/Express backend, and a separate Python FastAPI service running a BERT-based triage engine to route patient symptoms. Supports live video consultations over WebRTC and real-time chat via Socket.io, fully orchestrated with Docker Compose.

**Smart Allowance** — AI-powered blockchain allowance system deployed on Base Sepolia, built for The Synthesis Hackathon 2026 across three tracks. An LLM-driven agent manages spending rules and payments on-chain, with a live frontend and Railway-hosted backend.

**VaultMind** — Authorization runtime for multi-agent AI systems, built on Auth0 Token Vault. Issues intent-bound, single-use tokens and compiles plain-English permission rules directly into OAuth scopes, with trust decay and cryptographic delegation chains for safely passing permissions between agents.

**Sentinel** — Intent enforcement system for autonomous financial agents, built on the OpenClaw framework with Ed25519 cryptographic signing and single-use execution tokens. Every agent action is checked against a declared intent and logged to an immutable audit ledger, enforced by a real subprocess kernel over a Unix domain socket.

**Solo Task System** — Gamified productivity app inspired by the Solo Leveling aesthetic, turning everyday tasks into an RPG-style progression system to make building habits more engaging.

**TravelFlow** — Travel planning tool for mapping out routes and itineraries, focused on clean, practical multi-stop trip organization.

**TrustCheck AI** — AI-powered scam detection tool that analyzes messages and content to flag likely fraud before it costs the user money.
