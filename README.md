## Featured Projects

**GhostID** is an AI-powered continuous authentication system that prevents session hijacking using behavioral biometrics with zero user friction. Instead of authenticating a user once at login, it continuously verifies identity in the background by analyzing keystroke dynamics throughout the session. The core model is a 2-layer LSTM (hidden size 256, dropout 0.3, batch normalization) trained on the CMU Keystroke Dynamics dataset — 51 users and over 20,000 samples — using 41 engineered features per sample. The key design decision was building ratio-preserved features (comparing timing between consecutive keystrokes rather than raw timing values), so the model's fingerprint of a user survives natural variation in typing speed, and an impostor can't spoof identity by simply typing faster or slower. The trained model is exported to ONNX for lightweight, fast inference, and the project ships as a full system: a FastAPI backend for scoring sessions, a vanilla JavaScript SDK that other apps can drop in, and a React dashboard for visualizing session trust scores in real time.

**MedAssist** is a full-stack healthcare platform built to connect patients with care through an AI-assisted triage flow. The frontend is React/Vite, the main backend is Node.js/Express handling auth and business logic, and a separate Python FastAPI service runs a BERT-based triage engine that interprets patient-described symptoms and routes them appropriately. The platform supports live doctor-patient video consultations over WebRTC and real-time chat via Socket.io, with Redis used for session and cache management. The entire system is orchestrated through Docker Compose so all services — frontend, two backends, database, and cache — spin up together. Because the AI triage service runs on a free-tier host with cold-start delays, the project includes a wake-ping helper with retry logic and a user-facing "waking up the AI engine" message, so the experience degrades gracefully instead of just timing out.

**Smart Allowance** is an AI-powered blockchain allowance system deployed on Base Sepolia testnet, built for The Synthesis Hackathon 2026 and submitted across three separate competition tracks (Open, Agents that Pay, and Private Agents Trusted Actions). The core idea is an autonomous AI agent that manages allowance logic and payments on-chain without manual approval for every transaction, using an LLM (Groq's Llama 3.1) to interpret spending rules and make decisions within defined limits. It has a live deployed frontend and a Railway-hosted backend handling the off-chain coordination between the AI agent and the smart contract.

**VaultMind** is an authorization runtime built specifically for multi-agent AI systems, where the challenge isn't authenticating a human but scoping what an autonomous AI agent is allowed to do on someone's behalf. It's built on Auth0's Token Vault and issues intent-bound, single-use tokens — so a token only works for the specific action it was created for, and can't be replayed or reused for something else. A natural language policy compiler takes plain-English rules ("this agent can read my calendar but not modify it") and compiles them directly into OAuth scopes. The system also models trust decay, where an agent's permissions can automatically tighten over time or after anomalies, and supports cryptographic delegation chains so permissions can be safely passed from one agent to another while remaining fully auditable.

**Sentinel** is an intent enforcement system for autonomous financial agents, built for the ArmorIQ Claw and Shield x AI Club 2026 Hackathon using the OpenClaw framework. The problem it addresses is that once you give an AI agent the ability to move money or take financial actions, you need a way to guarantee it only does what it was explicitly authorized to do — Sentinel enforces that boundary. Every action an agent wants to take is checked against a declared intent and signed using Ed25519 cryptographic signing, with single-use execution tokens preventing replay attacks. All actions are recorded to an immutable audit ledger, and the enforcement layer runs as a real subprocess kernel communicating over a Unix domain socket using JSON-RPC, rather than being a simulated or mocked component.

**Solo Task System** is a gamified productivity app built around the aesthetic of Solo Leveling, turning everyday tasks into an RPG-style progression system. Instead of a flat to-do list, completing tasks levels up a character, building a game-like feedback loop that makes forming habits and hitting goals more engaging than a typical productivity app.

**TravelFlow** is a travel planning tool for mapping out routes and itineraries, built with a focus on clean, practical trip organization rather than generic listing of tourist spots. It's designed to help users plan multi-stop trips efficiently and keep the whole itinerary organized in one place.

**TrustCheck AI** is an AI-powered scam detection tool that analyzes messages and content to flag likely fraud before it costs someone money. It applies AI-based pattern analysis to identify common scam tactics in text, aiming to give users an early warning system for phishing, fraud, and social engineering attempts.
